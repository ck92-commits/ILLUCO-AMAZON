# Glossary

Shorthand and Amazon terms used on ILLUCO work.

## Acronyms
| Term | Meaning | Context |
|------|---------|---------|
| ASIN | Amazon Standard Identification Number | One per product or variation |
| A+ | A+ Content | Enhanced brand content modules below the description |
| SP | Sponsored Products | Keyword/product-targeted ads |
| SB | Sponsored Brands | Headline ads with logo + products |
| SBV | Sponsored Brands Video | Video version of SB; needs product demo videos |
| SD | Sponsored Display | Display/retargeting ads |
| PPC | Pay-per-click | Amazon ads in general |
| SEM | Search engine marketing | Here: Amazon PPC + Google Ads |
| ACoS | Advertising cost of sales | Ad spend ÷ ad-attributed sales |
| TACoS | Total ACoS | Ad spend ÷ total sales |
| CVR | Conversion rate | Unit session percentage in Business Reports |
| CTR | Click-through rate | Clicks ÷ impressions |
| S&S | Subscribe & Save | Repeat-purchase discount program |
| VOC | Voice of the Customer | Seller Central dashboard with return/complaint reasons |
| SQP | Search Query Performance | Brand Analytics report |
| DMR | Dental Mirror Revamp | Project started 11/05/2026 |
